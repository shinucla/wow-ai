In-game LLM features

Ideation · 2026-10-03 · topic in-game-llm-features
Focus: go-bridge LLM path — seed: BG combat analysis (healers / rotations)
Mode: this codebase (wow-ai addon ↔ Go bridge ↔ LLM)

Grounding context

wow-ai already has three non-mixed modes (assist / whisper / party), a ~3.2 KB pixel strip, ≤900 B game context (self only: zone, talents, quests…), map marks, and macro install buttons. There is no combat-log pipeline. Party auto-chat deliberately ignores raid/BG. Assist is the only coaching-fit path. README forbids memory-read / input injection.

Outside: WowCoach / ParsePal own post-fight raid coaching; BG/PvP LLM debrief is nearly empty. BattleComm / HHTD show BG telemetry prior art. Strong pattern: compute metrics locally, let the LLM narrate (VLML). Mid-combat LLM callouts are latency- and ToS-hostile; between-fight / post-match is the safe lane.

1. Scoreboard Moneyball debrief

match / combat review Conf 85% Cx Medium

At BG/arena end (and optionally mid-match), read GetBattlefieldScore for every player — class, damage, healing, kills, objectives — pack ~12 B/player, compute ranks in the bridge, and have the LLM write a short debrief: who carried heals, who padded overkill, who underperformed for their role. Auto-trigger on match end; keep history bridge-side for “vs your last N matches.”

direct: no GetBattlefield* usage in repo today; external: empty BG LLM coach niche; VLML metrics→narrative

Why it matters: This is your seed (“who is the healer?”) without CLEU range limits, and the cheapest end-to-end proof of a match-review product.

Downsides: Healing-done is a heuristic for “healer,” not role API; mid-match scoreboard freshness needs a live check on 3.3.5a.

2. Death autopsy

between-fight coaching Conf 80% Cx Medium

Keep a short ring buffer of damage/CC taken (and key CDs available). On PLAYER_DEAD, send ~300 B. Reply lands on the spirit-healer screen: “3 sources, trinket unused, Frost Nova unbroken.” Use a compact scorecard notation so the payload fits strip/context budgets.

direct: no CLEU/death-recap code; PLAYER_DEAD is free out-of-combat window; strip can deliver while dead

Why it matters: Hits the most emotional coaching moment with tiny engineering vs a full log pipeline.

Downsides: Coarse buffers miss one-shots; notation design is the real product work.

3. Fight ledger + metrics → rotation critique

match / combat review Conf 75% Cx High

Add a CLEU collector that seals a fixed-size digest at PLAYER_REGEN_ENABLED (casts, interrupts, idle gaps, CD uses — nearby players only). Go computes uptime / interrupt rate / wasted CDs; the LLM only narrates anomalies. Answers “whose rotations need work” for whoever you could see.

direct: CLEU unused but listed in primer; external: WowCoach/ParsePal pattern; reasoned: never ship raw logs through 3.2 KB strip

Why it matters: One ledger unlocks debriefs, baselines, and future callout modes; numbers stay trustworthy.

Downsides: CLEU range ≠ whole BG; client event shape needs a Forever vs 3.3.5a check; highest build cost of the set.

4. Precompute playbook (LLM off the hot path)

between-fight coaching Conf 70% Cx Medium

During BG prep (or before a pull), spend one slot on a short playbook: enemy class mix, focus priorities, 2–3 contingency lines. During the match, local triggers or wav cues print a prewritten line — no mid-fight LLM round trip (5–60 s is too slow for callouts).

reasoned: strip/slot latency kills live coaching; architecture already has free wav signals; external: boxing corner / F1 pre-agreed calls

Why it matters: Makes “real-time-feeling” advice possible without pretending the coding-agent CLI is a GCD timer.

Downsides: Wav codebook needs careful index budgeting; bad playbooks hallucinate 3.3.5a spells — keep advice checkable.

5. Bridge game-data pack

open-world guidance Conf 80% Cx High

Ship (or plug in) a versioned WotLK quest/NPC/coord pack on the bridge. Enrich quest-log IDs from GameContext into titles, objectives, and map points before prompting. Existing wowmap / navigator then draw real routes instead of guessing.

direct: MAP.md — bridge ships no game data; quest context is ids only

Why it matters: Map/route plumbing exists but is starved; one data layer lifts open-world assist dramatically.

Downsides: Data licensing + size; navigator still weak in instances/BGs.

6. Context priority packer

open-world guidance Conf 90% Cx Low

Replace blind s:sub(1,900) truncation (quests are last → mid-id chops) with a priority packer: character + location first, then whole quest lines or an explicit “N more” marker. Cheap correctness fix that makes every later feature’s prompts saner.

direct: WoWAI.lua CONTEXT_MAX truncation; open-world dossier

Why it matters: Silent data loss today; unlocks trustworthy “what next?” answers.

Downsides: Still only 900 B — doesn’t add gear/bars by itself (that’s a later sectioned context design).

7. One-shot build / kit audit

character & loadout craft Conf 75% Cx Low

/wow-ai audit (or an assist command) dumps talent ranks + equipped item links in one <3 KB assist send. LLM returns gaps (missing enchants, unspent points, function holes like “no snare break”) and optional wowmacro buttons — reusing the existing install path.

direct: GameContext has tab totals only; gear needs manual shift-clicks today; wowmacro pipeline exists

Why it matters: Safe, non-combat, high-trust use of assist; closes the loop from advice → installable macro.

Downsides: No item DB → avoid inventing bis lists; stick to observable gaps.
